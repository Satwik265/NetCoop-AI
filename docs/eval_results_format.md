# Evaluation Benchmark Results Specification

## 1. Overview
This document specifies the exact JSON format and schema for diagnostic evaluation benchmark results generated by the evaluation engine and visualized on the Proof / Evaluation tab by Member C.

Standard output location:
`eval/results/<benchmark_id>.json` (mock fixture at `eval/results/mock.json`).

## 2. Top-Level Schema Fields

| Field | Type | Description |
| :--- | :--- | :--- |
| `version` | string | Benchmark schema version (`1.0.0`) |
| `generated_at` | string | ISO 8601 UTC timestamp of benchmark execution |
| `summary` | object | Aggregate performance KPIs across test samples |
| `dataset_splits` | object | Accuracy comparison across in-distribution, held-out, and organizer datasets |
| `per_class_metrics` | object | Per-fault precision, recall, F1-score, and support counts |
| `confusion_matrix` | object | Ordered class names and 2D NxN prediction matrix |
| `calibration` | object | Expected Calibration Error (ECE) and reliability diagram bins |
| `stress_tests` | object | Robustness curves under missing data rates and noise corruption rates |
| `risk_coverage` | array | Risk-coverage tradeoff points across confidence thresholds |
| `ablation_table` | array | Ablation study comparing pipeline configurations |

## 3. Detailed Field Definitions

### 3.1 `summary`
- `total_samples` (integer): Total incidents evaluated.
- `overall_accuracy` (float): Correct classification proportion `[0.0, 1.0]`.
- `macro_f1` (float): Unweighted mean F1-score across all classes.
- `weighted_f1` (float): Support-weighted mean F1-score.
- `expected_calibration_error` (float): Calibration error metric `[0.0, 1.0]`.
- `brier_score` (float): Mean squared error of probabilistic predictions.

### 3.2 `dataset_splits`
- `in_distribution_accuracy` (float): Synthetic test set accuracy.
- `in_distribution_samples` (int): Number of in-distribution samples.
- `held_out_accuracy` (float): Unseen parameter range / topology accuracy.
- `held_out_samples` (int): Number of held-out samples.
- `organizer_accuracy` (float): External organizer Colab format accuracy.
- `organizer_samples` (int): Number of organizer samples.

### 3.3 `per_class_metrics`
Keyed by canonical scenario names (`normal_operation`, `link_congestion`, `weak_wifi_signal`, `ethernet_interface_fault`, `dns_failure`, `dhcp_failure`, `device_cpu_overload`, `upstream_failure_cascade`, `ambiguous_multi_fault`, `insufficient_data`):
```json
{
  "precision": 0.941,
  "recall": 0.941,
  "f1": 0.941,
  "support": 17
}
```

### 3.4 `confusion_matrix`
- `classes`: Array of strings specifying row and column order.
- `matrix`: 2D array of integers `matrix[actual_index][predicted_index]`.

### 3.5 `calibration`
- `expected_calibration_error` (float): ECE score.
- `max_calibration_error` (float): Maximum calibration deviation in any bin.
- `reliability_bins`: Array of 5-10 objects:
  - `bin_lower` (float): Lower confidence bound.
  - `bin_upper` (float): Upper confidence bound.
  - `mean_confidence` (float): Average predicted confidence in bin.
  - `accuracy` (float): Empirical accuracy in bin.
  - `sample_count` (int): Number of predictions assigned to bin.

### 3.6 `stress_tests`
- `accuracy_vs_missing_data_rate`: Array of `{ "missing_rate": float, "accuracy": float, "samples": int }` (rates 0.0 to 0.7).
- `accuracy_vs_corruption_rate`: Array of `{ "corruption_rate": float, "accuracy": float, "samples": int }` (rates 0.0 to 0.6).

### 3.7 `risk_coverage`
Array of points depicting selective classification performance:
- `coverage` (float): Proportion of samples accepted `[0.0, 1.0]`.
- `risk` (float): Error rate among accepted samples.
- `confidence_threshold` (float): Required minimum confidence to accept.

### 3.8 `ablation_table`
Comparative ablation studies containing:
- `configuration` (string): Pipeline variant name.
- `accuracy` (float): Classification accuracy.
- `f1_score` (float): F1-score.
- `ece` (float): Calibration error.
- `avg_latency_ms` (float): Mean round-trip processing time in ms.
- `insufficient_evidence_rate` (float): Rate of fallback to `insufficient_evidence`.
