# Evaluation Benchmark Results Specification

## 1. Overview
This document specifies the exact JSON format and schema for diagnostic evaluation benchmark results generated by the evaluation engine and visualized on the Proof / Evaluation tab by Member C.

Standard output locations:
- `eval/results/benchmark_latest.json` (canonical authoritative benchmark run)
- `eval/results/mock.json` (synchronized fixture for dashboard offline testing)

---

## 2. Top-Level Schema Fields

| Field | Type | Description |
| :--- | :--- | :--- |
| `version` | string | Benchmark schema version (`1.0.0`) |
| `evaluation_mode` | string | Evaluation execution mode: `"quick"` or `"full"` |
| `generated_at` | string | ISO 8601 UTC timestamp of benchmark execution |
| `reproducibility` | object | Seed ranges, split specifications, and conformal significance $\alpha$ |
| `summary` | object | Unambiguous aggregate performance KPIs across test samples |
| `dataset_splits` | object | Accuracy and parameter coverage across in-distribution, held-out, and organizer datasets |
| `per_class_metrics` | object | Per-fault precision, recall, F1-score, and true support counts |
| `confusion_matrix` | object | Ordered class names and 2D NxN prediction matrix |
| `calibration` | object | Expected Calibration Error (ECE) and reliability diagram bins |
| `stress_tests` | object | Robustness curves under missing data rates and noise corruption rates |
| `risk_coverage` | array | Risk-coverage tradeoff points across confidence thresholds |
| `ablation_table` | array | Ablation study comparing pipeline configurations |

---

## 3. Detailed Field Definitions

### 3.1 `summary`
- `evaluation_mode` (string): `"quick"` (100 total samples) or `"full"` (1,300 total samples).
- `total_evaluation_samples` (integer): Total incidents evaluated across all partitions (in-distribution, held-out, organizer).
- `primary_in_distribution_samples` (integer): Number of in-distribution samples evaluated under `DatasetSplitter.TEST_SPEC`.
- `primary_in_distribution_accuracy` (float): Empirical accuracy on in-distribution test samples `[0.0, 1.0]`.
- `held_out_samples` (integer): Number of held-out samples evaluated via blind generator.
- `held_out_accuracy` (float): Empirical accuracy on unseen topology and layout holdouts.
- `organizer_samples` (integer): Number of hackathon organizer samples evaluated.
- `organizer_set_match_accuracy` (float): Set-match accuracy on organizer format (handles ambiguous multi-fault saturation).
- `organizer_exact_match_accuracy` (float): Strict exact-match accuracy on organizer format.
- `combined_primary_accuracy` (float): Aggregate correctness across in-distribution and held-out primary benchmarks.
- `selective_accuracy` (float): Classification accuracy on the subset of cases where the pipeline emitted a diagnosis (`status == "diagnosed"`).
- `coverage` (float): Fraction of samples receiving a definitive diagnosis.
- `selective_risk` (float): Empirical error rate on diagnosed cases ($1.0 - \text{selective\_accuracy}$).
- `safe_abstention_rate` (float): Proportion of ambiguous or insufficient-data cases where the system safely abstained to `insufficient_evidence`.
- `macro_f1` (float): Unweighted mean F1-score across evaluated canonical classes.
- `weighted_f1` (float): Support-weighted mean F1-score.
- `macro_f1_classes` (array of strings): Canonical class names over which macro F1 is computed.
- `macro_f1_population` (string): Specific population descriptor (e.g. `"in_distribution_and_heldout_primary_samples"`).
- `expected_calibration_error` (float): ECE metric across 5 probability bins `[0.0, 1.0]`.
- `ece_population` (string): Population over which ECE is evaluated.
- `brier_score` (float): Mean squared error of probabilistic predictions.
- `brier_score_population` (string): Population over which Brier score is computed.

> [!NOTE]
> Legacy compatibility aliases (`total_samples`, `primary_benchmark_samples`, `overall_accuracy`) are preserved in `summary` to avoid breaking downstream consumers.

### 3.2 `dataset_splits`
- `in_distribution_accuracy` (float): Synthetic test set accuracy under `TEST_SPEC`.
- `in_distribution_samples` (int): Number of in-distribution test samples (20 quick, 250 full).
- `in_distribution_parameter_coverage` (object): Verified parameter distributions:
  - `missing_rate_min`, `missing_rate_max`, `missing_rate_mean`: Sampled missingness rates in `[0.2, 0.6]`.
  - `onset_offset_min`, `onset_offset_max`, `onset_offset_mean`: Sampled onset offsets in `[60.0, 180.0]`.
- `held_out_accuracy` (float): Accuracy on blind generator holdouts (20 quick, 150 full).
- `held_out_samples` (int): Number of held-out samples.
- `organizer_accuracy` (float): Organizer set-match accuracy (60 quick, 900 full).
- `organizer_exact_accuracy` (float): Organizer exact-match accuracy.
- `organizer_samples` (int): Total organizer telemetry records evaluated.
- `organizer_windowed_accuracy` (float): Accuracy on 3-point windowed organizer telemetry.
- `organizer_single_snapshot_accuracy` (float): Accuracy on single-snapshot organizer telemetry.

### 3.3 `per_class_metrics`
Keyed by canonical scenario names (`normal_operation`, `link_congestion`, `weak_wifi_signal`, `ethernet_interface_fault`, `dns_failure`, `dhcp_failure`, `device_cpu_overload`, `upstream_failure_cascade`):
```json
{
  "precision": 0.950,
  "recall": 0.950,
  "f1": 0.950,
  "support": 25
}
```
Every ground-truth sample with a label in the class list contributes to support. Out-of-class predictions (such as unassigned or abstained predictions) are counted as false negatives and penalize recall and F1.

### 3.4 `confusion_matrix`
- `classes`: Array of 8 canonical class names defining row and column order.
- `matrix`: 2D array of integers `matrix[actual_index][predicted_index]`.

### 3.5 `calibration`
- `expected_calibration_error` (float): ECE score.
- `max_calibration_error` (float): Maximum calibration deviation in any bin.
- `reliability_bins`: Array of 5 bin objects with `bin_lower`, `bin_upper`, `mean_confidence`, `accuracy`, and `sample_count`.

### 3.6 `stress_tests`
- `accuracy_vs_missing_data_rate`: Robustness sweep across missing rates (0.0 to 0.7).
- `accuracy_vs_corruption_rate`: Robustness sweep across burst noise levels (0.0 to 0.6).

### 3.7 `risk_coverage`
Selective classification points across confidence thresholds:
- `threshold` (float): Minimum confidence threshold.
- `coverage` (float): Proportion of samples accepted `[0.0, 1.0]`.
- `selective_risk` (float): Error rate among accepted samples.
- `accepted_samples` (int): Number of predictions satisfying the threshold.

### 3.8 `ablation_table`
Comparative ablation studies containing:
- `configuration` (string): Pipeline variant name.
- `accuracy` (float): Classification accuracy.
- `f1_score` (float): Macro F1 score across all evaluated scenarios (single-agent baseline correctly evaluated at ~0.25).
- `ece` (float): Calibration error.
- `avg_latency_ms` (float): Mean round-trip processing time in ms.
- `insufficient_evidence_rate` (float): Rate of fallback to `insufficient_evidence`.
